3 tips para decorar cupcakes

🧁

1. Deja enfriar completamente el cupcake antes de decorar.
2. Usa una manga pastelera para un acabado más parejo.
3. Agrega el topping (fruta, chocolate) justo antes de servir para que se vea fresco.
